## 結論

`ls` は、ディレクトリ内のファイルやフォルダを一覧表示するコマンド。

現在いる場所の中身を確認したり、指定したディレクトリに何があるかを確認するときに使う。

## 基本形

```bash
ls
```

現在のディレクトリにあるファイルやフォルダを表示する。

```bash
ls path/to/dir
```

指定したディレクトリの中身を表示する。

## よく使う形

```bash
ls -la
```

隠しファイルも含めて、詳細情報つきで一覧表示する。

```bash
ls -lh
```

ファイルサイズを読みやすい単位で表示する。

```bash
ls -lt
```

更新日時が新しい順に表示する。

```bash
ls -ltr
```

更新日時が古い順に表示する。

ログファイルや生成物の時系列を確認するときに便利。

## オプション

| オプション | 意味 |
| --- | --- |
| `-l` | 詳細表示する |
| `-a` | 隠しファイルも表示する |
| `-h` | ファイルサイズを読みやすい単位で表示する |
| `-t` | 更新日時順に並べる |
| `-r` | 並び順を逆にする |
| `-R` | サブディレクトリも再帰的に表示する |

## 見方

```bash
ls -la
```

表示例。

```text
drwxr-xr-x  5 user  staff   160 Jun 16 10:00 .
drwxr-xr-x  8 user  staff   256 Jun 16 09:50 ..
-rw-r--r--  1 user  staff  1024 Jun 16 09:55 README.md
```

先頭の文字で種類が分かる。

| 表示 | 意味 |
| --- | --- |
| `d` | ディレクトリ |
| `-` | 通常ファイル |
| `l` | シンボリックリンク |

## 使いどころ

- ファイルが存在するか確認する
- 隠しファイルを確認する
- ファイルサイズや更新日時を見る
- 作業前にディレクトリの状態をざっと把握する

## 注意点

`ls` は表示するだけのコマンドなので、基本的にファイルを変更しない。

ただし、ファイル数が非常に多いディレクトリで `ls -R` を使うと出力が大量になる。
