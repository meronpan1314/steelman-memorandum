## 結論

レンダリングは、データやコードを画面に表示できる形へ変換する処理である。

Webでは、HTML・CSS・JavaScriptなどをもとにブラウザが画面を描画することを指す。

---

## 1. レンダリングとは何か

レンダリングは「描画する」「表示する」という意味。

Webページでは、ブラウザが受け取ったHTMLやCSSを解析し、ユーザーが見える画面に変換する。

```text
HTML / CSS / JavaScript
        ↓
ブラウザが解釈
        ↓
画面表示
```

---

## 2. Webでのレンダリング

Webアプリでは、主に以下のようなレンダリング方式がある。

### ■ サーバーサイドレンダリング

サーバー側でHTMLを作ってブラウザに返す。

```text
サーバー → 完成済みHTML → ブラウザ
```

### ■ クライアントサイドレンダリング

ブラウザ側のJavaScriptで画面を作る。

```text
サーバー → データ + JS → ブラウザで画面生成
```

---

## 3. なぜ重要なのか

レンダリング方式は、以下に影響する。

- 初期表示速度
- SEO
- ユーザー体験
- サーバー負荷
- フロントエンドの複雑さ

画面をどこで作るかによって、設計が変わる。

---

## 4. 関連用語

| 用語 | 意味 |
| --- | --- |
| SSR | サーバー側でHTMLを生成する |
| CSR | ブラウザ側で画面を生成する |
| Hydration | サーバー生成HTMLにJavaScriptの動きを接続する |
| Re-render | 状態変更により再描画する |

---

## 5. まとめ

- レンダリングは画面に表示できる形へ変換すること
- Webではブラウザの描画処理を指すことが多い
- SSRとCSRで画面生成の場所が違う
- 表示速度や設計に影響する重要な概念
