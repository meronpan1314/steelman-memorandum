## 結論

テンプレートエンジンは、HTMLなどのひな形にデータを埋め込んで、最終的な画面を生成する仕組みである。

サーバー側でHTMLを作るときによく使われる。

---

## 1. テンプレートとは何か

テンプレートは、表示のひな形。

固定のHTMLの中に、後から埋め込む場所を用意しておく。

```html
<h1>{{ title }}</h1>
<p>{{ message }}</p>
```

ここにデータを入れると、完成したHTMLになる。

```html
<h1>お知らせ</h1>
<p>メンテナンスがあります</p>
```

---

## 2. なぜ使うのか

HTMLを文字列連結で作ると、読みにくく壊れやすい。

```java
String html = "<h1>" + title + "</h1>";
```

テンプレートエンジンを使うと、HTMLの構造とデータ埋め込みを分けられる。

---

## 3. 代表例

- Thymeleaf
- JSP
- FreeMarker
- Mustache
- Handlebars
- Jinja2

JavaのSpring Bootでは、Thymeleafが使われることがある。

---

## 4. サーバーサイドレンダリング

テンプレートエンジンは、サーバーサイドレンダリングと関係が深い。

サーバー側でHTMLを完成させてから、ブラウザへ返す。

```text
サーバー
  └─ テンプレート + データ
      ↓
    HTML
```

---

## 5. まとめ

- テンプレートエンジンはHTMLなどのひな形にデータを埋め込む仕組み
- 文字列連結より読みやすく管理しやすい
- サーバー側でHTMLを生成する場面で使われる
- Thymeleaf、JSP、Jinja2などが代表例
