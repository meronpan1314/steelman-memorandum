## 結論

アクセサーは、クラスのフィールドに外部からアクセスするためのメソッドである。

代表例は getter と setter。

---

## 1. アクセサーとは何か

オブジェクト指向では、フィールドを直接外部に公開しないことが多い。

```java
class User {
    private String name;
}
```

この `name` に外部からアクセスするために、メソッドを用意する。

```java
public String getName() {
    return name;
}

public void setName(String name) {
    this.name = name;
}
```

このようなメソッドをアクセサーと呼ぶ。

---

## 2. getter

getterは、値を取得するためのメソッド。

```java
public String getName() {
    return name;
}
```

外部からは以下のように使う。

```java
String name = user.getName();
```

---

## 3. setter

setterは、値を設定するためのメソッド。

```java
public void setName(String name) {
    this.name = name;
}
```

外部からは以下のように使う。

```java
user.setName("Taro");
```

---

## 4. なぜ直接フィールドを触らないのか

フィールドを直接公開すると、どこからでも自由に変更できてしまう。

```java
user.name = "";
```

setterを使えば、値のチェックを挟める。

```java
public void setName(String name) {
    if (name == null || name.isBlank()) {
        throw new IllegalArgumentException("name is required");
    }
    this.name = name;
}
```

---

## 5. 注意点

全フィールドに機械的にgetter/setterを作ると、結局なんでも変更できるクラスになる。

本当に外部から変更してよい値だけ setter を用意する。

---

## 6. まとめ

- アクセサーはフィールドへアクセスするためのメソッド
- getterは取得、setterは設定
- フィールドを直接公開せず、制御を挟める
- setterを増やしすぎるとカプセル化が弱くなる
