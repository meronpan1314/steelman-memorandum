## 結論

HTTP通信は、Webブラウザやアプリがサーバーとデータをやり取りするための通信方式である。

クライアントがリクエストを送り、サーバーがレスポンスを返す。

---

## 1. HTTPとは何か

HTTP（HyperText Transfer Protocol）は、Webで使われる代表的な通信プロトコル。

プロトコルとは「通信するときの決め事」のこと。

HTTPでは、基本的に以下の流れで通信する。

```text
クライアント → Request  → サーバー
クライアント ← Response ← サーバー
```

---

## 2. リクエスト

リクエストは、クライアントからサーバーへの依頼。

主な要素は以下。

- メソッド
- URL
- ヘッダー
- ボディ

例：

```http
GET /users/1 HTTP/1.1
Host: example.com
```

---

## 3. レスポンス

レスポンスは、サーバーからクライアントへの返答。

主な要素は以下。

- ステータスコード
- ヘッダー
- ボディ

例：

```http
HTTP/1.1 200 OK
Content-Type: application/json

{"id": 1, "name": "Taro"}
```

---

## 4. HTTPメソッド

| メソッド | 役割 |
| --- | --- |
| GET | データを取得する |
| POST | データを作成・送信する |
| PUT | データを全体更新する |
| PATCH | データを部分更新する |
| DELETE | データを削除する |

---

## 5. ステータスコード

| 範囲 | 意味 |
| --- | --- |
| 2xx | 成功 |
| 3xx | リダイレクト |
| 4xx | クライアント側のエラー |
| 5xx | サーバー側のエラー |

例：

- `200 OK`
- `201 Created`
- `400 Bad Request`
- `401 Unauthorized`
- `404 Not Found`
- `500 Internal Server Error`

---

## 6. まとめ

- HTTPはWeb通信の基本プロトコル
- クライアントがリクエストを送り、サーバーがレスポンスを返す
- メソッドは操作の種類を表す
- ステータスコードは処理結果を表す
